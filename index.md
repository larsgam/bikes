# Bikes

Interactive tools for understanding bicycle frames — built on a hand-verified
library of manufacturer geometry charts, independent lab measurements and
spec-sheet data.

<a class="card" href="{{ '/frame-explorer/' | relative_url }}">
  <b>Frame Explorer</b>
  <p>Pick up to five frames from the library and compare them: true-to-scale
  geometry overlay with a fit window, dimension drawings, a four-axis character
  profile (position, handling, lightness, aero), verified spec cards and
  measurement bar charts. 17 model families, ~90 sizes.</p>
</a>
